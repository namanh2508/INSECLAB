# INSECLAB

Security research workspace. The active project is the **Agentic AI Security
Evaluation Tool** under [`agentic_security_eval/`](agentic_security_eval/) — an
evaluator that probes target agentic systems for OWASP Agentic Security
Initiative (ASI) risks: ASI01 Goal Hijack, ASI02 Tool Misuse, and ASI06 Memory &
Context Poisoning.

## Start here

- [agentic_security_eval/README.md](agentic_security_eval/README.md) — what the
  tool does, installation, and CLI usage.
- [agentic_security_eval/docs/architecture.md](agentic_security_eval/docs/architecture.md)
  — pipeline, evidence trust model, and how to author an evidence rule.
- [AGENTS.md](AGENTS.md) — repository-wide agent/contributor operating rules;
  [agentic_security_eval/AGENTS.md](agentic_security_eval/AGENTS.md) adds the
  package-specific architecture and evidence invariants.

All current work lives under `agentic_security_eval/`.
